
# ephc 🇵🇾
Datos EPHC Trimestral (.csv, .dta)

## Objetivos
- Almacenar los archivos de datos de la Encuesta Permanente de Hogares Continua (EPHC) elaborada por el Instituto de Estadísticas del Paraguay (INE).
- Mostrar algunos ejemplos de Econometría Aplicada de Corte Transversal con la EPHC.
- Los ejemplos están elaborados en archivos do-file de Stata y en scripts de Python (próximamente).
- Estas aplicaciones están dirigidas a los alumnos de Economía de la Universidad Católica "Nuestra Señora de la Asunción" que están desarrollando sus trabajos finales de grado.

## Estructura
- Contiene dos directorios con archivos de datos: "archivos_csv_ine" y "archivos_dta_ine". El primero con los archivos originales descargados de la web de INE en formato .CSV y el segundo contiene los archivos en formato .DTA.
- El directorio "do-files" contiene los scripts de Stata que permiten crear variables, estimar modelos
